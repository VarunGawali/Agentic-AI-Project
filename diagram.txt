┌─────────────────────────────────────────────────────────────────────────────────┐
│  QUANT PERFORMANCE FEATURES                                                     │
│  ① Vectorized MC      — matrix ops, no Python loops in hot path                │
│  ② Multiprocessing    — ProcessPoolExecutor, parallel candidate sweep          │
│  ③ Sobol sequences    — O(1/N) convergence vs O(1/√N) plain MC                │
│  ④ Antithetic variates— halved estimator variance, zero extra paths            │
│  ⑤ Bootstrap 95% CIs — on mean cost and CVaR (500 resamples)                  │
│  ⑥ AIC window select  — auto-calibrates GBM fit window from history            │
│  ⑦ joblib path cache  — skips GBM recompute on identical inputs               │
